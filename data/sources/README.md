# Official Leipzig boundary snapshot

`leipzig-municipal-boundary.geojson` is an **unchanged** snapshot of the ten
official Leipzig city districts, in EPSG:25833. The municipal extraction stage
dissolves all ten features for the clipping boundary.

- Publisher and attribution: Stadt Leipzig, Amt für Statistik und Wahlen,
  Geodaten der Stadtbezirke der Stadt Leipzig.
- [Official dataset](https://opendata.leipzig.de/dataset/geodaten-stadtbezirke-leipzig).

- [Original download](https://static.leipzig.de/fileadmin/mediendatenbank/leipzig-de/Stadt/02.1_Dez1_Allgemeine_Verwaltung/12_Statistik_und_Wahlen/Geodaten/Stadtbezirke_Leipzig_UTM33N.json).

The source lock uses a commit-addressed URL for this snapshot because the
official host intermittently resets streamed downloads. This mirror records
the exact official input, not newly inferred or edited boundary geometry.
Do not replace the snapshot in place to upgrade the locked data: choose and
verify a new source version and preserve the old cache and provenance.
